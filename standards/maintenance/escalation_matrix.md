# Escalation Matrix Standard

## Purpose
Define who (or which orchestrator) handles which type of problem.

## Examples

- Security issues → Security/Compliance + Governance Orchestrator.
- Gameplay-breaking bugs → GameOps Orchestrator + Architect.
- Monetization issues → Patreon Orchestrator + Business stakeholders.
- Community safety issues → Discord Orchestrator + Governance Orchestrator.

All agents MUST consult this matrix when escalation rules are triggered.
