# Architecture Document Standard

## Purpose
Ensure all architecture documents follow a common structure for clarity and automation.

## Required Sections

1. **Overview**
   - Summary of the system or feature.
   - Scope and out-of-scope items.

2. **Context Diagram**
   - High-level diagram of systems and interactions.

3. **Components**
   - List of services, agents, databases, and external APIs.
   - Responsibilities and boundaries.

4. **Data Flow**
   - How data moves between components.
   - Key transformations.

5. **Failure Modes & Resilience**
   - What can go wrong.
   - How the system responds or degrades.

6. **Security & Privacy**
   - Sensitive data.
   - Access controls.

7. **Operational Concerns**
   - Monitoring.
   - Scaling.
   - Deployment considerations.

Systems Designer Agents MUST produce architecture docs with these sections.
