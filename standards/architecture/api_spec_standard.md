# API Specification Standard

## Purpose
Define service and agent APIs with enough detail for code generation and compatibility checks.

## Content

1. **Endpoint List**
   - Method, path, summary.

2. **Request Schema**
   - JSON schema or equivalent for body, params, headers.

3. **Response Schema**
   - Success and error responses with status codes.

4. **Authentication**
   - How calls are authorized.

5. **Rate Limits / Quotas**
   - Limits, if any.

API Scaffolding and Code Generator Agents MUST respect these specs.
