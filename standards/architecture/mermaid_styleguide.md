# Mermaid Diagram Style Guide

## Purpose
Ensure all diagrams are readable, consistent, and parsable by agents.

## Rules

- Use `graph LR` or `graph TD` consistently within each doc.
- Prefer simple, descriptive node labels.
- Group related components using `subgraph`.
- Avoid excessive styling; clarity over decoration.
- Include a legend when using special icons or shapes.

All agents producing Mermaid diagrams MUST follow this style guide.
