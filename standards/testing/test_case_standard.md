# Test Case Standard

## Purpose
Provide a consistent structure for all test cases across units, integration, and simulation tests.

## Template

- **ID**: `TC-<area>-<number>`
- **Title**: Short description.
- **Preconditions**: Required state or configuration.
- **Steps**: Ordered list of steps.
- **Expected Result**: Clear pass/fail condition.
- **Related Requirements**: FR/AC IDs.

Test Case Generator Agents MUST output test cases using this structure.
