### aegis-poi #13 -- CallLater crash investigation state

Two real bugs found and fixed, confirmed via boot test with the throwaway key:

1. `AEGIS_POI_BlackMarket_ReputationGate`'s `map<EntityAI, int>` was keyed by a raw entity handle
   with no removal path when the entity was deleted -- a dangling-pointer crash. Fixed with
   `Unregister()`/`Clear()`, wired into `AEGIS_POI_BlackMarket.Shutdown()`.
2. `CheckCanUseTrader` passed `ExpansionTraderObjectBase` where `TryGetMinReputation` wants
   `EntityAI` -- a compile error that broke the whole World script module under Expansion.
   `ExpansionTraderObjectBase` holds an `EntityAI` (`GetTraderEntity()`) rather than extending one --
   verified against unpacked `market_scripts.pbo`, not guessed.

**Both are real and should stay in the PR.** Neither is the crash that's actually blocking Session 4
though. That crash (confirmed still reproducing after both fixes above) was bisected down to: it
reproduces from the mere presence of a `GetGame().GetCallQueue(CALL_CATEGORY_GAMEPLAY).CallLater(...)`
registration in `AEGIS_POI_BlackMarket_TestHarness`, independent of what the callback does -- proven
by removing everything from the callback bodies down to a bare `Print()` no-op and it still crashed
with the identical signature/address, while a harness with zero `CallLater` calls at all boots clean
and stays alive indefinitely. Also proven: this is NOT a generic `CallLater` bug in this engine --
the sibling `AEGIS_POI_TestHarness` (`restart-test.ps1`) uses the identical pattern and is confirmed
(via this plan's own Session 2 history, not just documentation) to have actually fired successfully
in a real passing run. One concrete unexplored lead remains: the crashing harness's `config.cpp`
`requiredAddons[]` includes a cross-PBO reference (`"AEGIS_POI_BlackMarket"`) the sibling doesn't
have -- ruled out as a "phantom/unloaded dependency" (the addon was proven loaded and functional via
a control test using the exact same deployed build), but not yet ruled out as a factor some other
way. Full bisection trail with every intermediate result: `aegis-poi/docs/PLAN.md`, "Paused
2026-09-14" section onward.

**Next concrete step, per the reconciliation with github-54's independent pass (relayed via
github-47, not yet independently verified by this session): one boot test comparing the identical
one-line `CallLater` registration under `aegis-mods`** (which boot-tests clean end-to-end). If it
